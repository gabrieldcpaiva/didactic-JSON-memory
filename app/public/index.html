        How this works
        
      
        Four steps, no magic. You can audit every one of them in the repo.
        
    
        

    
          
      
        1. Template
          Craft that does not change: blocks, locks, known failures. Frozen in JSON.
          2. 
      
        2. Values
          Only what changes: names, colors, headlines. Nine blanks, prefilled with real examples.
          3. 
      
        3. Memory
          Proven one-line lessons, selected by tag and score, capped by a character budget.
          4. 
      
        4. Render
          JSON becomes short labeled sentences. Never raw JSON — braces get painted into the picture.
          5. 
    
        

    
        
      
        
        
        The loop
        
        
        render  →  run  →  judge  →  score
   ↑                              │
   └──────── lessons ─────────────┘
        
        
        Two wins: active. −2: retired. Nothing else gets in.
        
      
        
      
        
        
        Honest limits
        
        
          
          
        • A rendered prompt is not a guarantee. Run it twice.
          • 
          
        • Text under ~12px in the final image still breaks.
          • 
          
        • This prepares prompts; it does not call the API.
          • 
          
        • SynthID is in every output. Do not pass them off as untouched photos.
          • 
          
        • Seed scores are priors. Score them yourself.
          •
